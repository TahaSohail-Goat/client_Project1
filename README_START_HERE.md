## Important non-negotiables

- Photos do **not** confirm which exteriors, interiors or physical model shots relate to one another. Showcase by category until client validates project assignments.
- Miniature model **photographs** do not equal a 3D model. R3F may animate photo planes, not invent a faithful navigable building.
- Current exteriors are ~1080 px wide. Limit hero zoom and request original large-resolution files for sharp large displays.
- Do not clone the source websites or reuse their pictures, copy, names, fake project figures or footage.
